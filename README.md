# 딱 맞춰! 분수카페

초등학교 4학년 분수의 덧셈과 뺄셈을 카페 운영 게임으로 학습하는 무료 교육 콘텐츠입니다.

기획·제작: 쓰로인훈쌤 김종훈

## 플레이

https://kkankong32-alt.github.io/fraction-cafe/

## 바로 실행

프로젝트 최상위의 `index.html`을 더블클릭하면 별도 서버 없이 실행됩니다.

## 개발 실행

```bash
npm install
npm run dev
```

## 검증 및 배포 빌드

```bash
npm test
npm run build
```

`dist` 폴더는 정적 웹 서버 또는 GitHub Pages에 그대로 배포할 수 있습니다. 외장·동기화 드라이브가 `node_modules`의 소파일 생성을 지원하지 않는 경우, 프로젝트를 로컬 디스크로 복사해 개발 명령을 실행하세요.

## 조작

- 마우스·터치: 재료 선택, 붓기/비우기(길게 누르기 지원), 계량 완료, 합치기, 서빙
- 키보드: 위/아래 방향키으로 한 눈금씩 조절, Enter로 계량 완료
- 도움말·학습 내용 창이 열린 동안 영업 시간과 손님 인내도는 정지합니다.

딱 맞춰! 분수카페 - 입장 퀴즈

1. 실행
분수카페의 기존 index.html이 있는 폴더 안에 'quiz' 폴더 전체를 둡니다.
'quiz/index.html'을 브라우저로 열면 입장 퀴즈가 시작됩니다.
학생에게는 게임 파일 대신 이 퀴즈 파일을 먼저 안내하세요.
인터넷 연결, 계정, 별도 설치 없이 퀴즈를 풀 수 있습니다.
분수카페의 원래 게임 파일은 변경하지 않습니다.

2. 폴더 배치
분수카페 폴더/
  index.html        <- 기존 분수카페 게임
  image/            <- 기존 게임 이미지
  audio/            <- 기존 게임 음악
  quiz/
    index.html      <- 학생이 먼저 여는 파일
    questions.js
    config.js
    app.js
    style.css
    샘퀴즈_입력용_10문항.txt
    image/          <- 퀴즈에서 사용하는 이미지 5개

3. 통과 규칙
10문제를 끝까지 풉니다. 각 문제를 채점한 뒤 해설을 읽고 다음으로 갑니다.
각 문제는 한 번만 점수에 반영됩니다.
7문제 이상 정답이면 결과 화면에서 3초 후 분수카페로 이동합니다.
'지금 분수카페 입장하기' 버튼으로 바로 입장할 수도 있습니다.
'해설 더 보기'를 누르면 자동 이동이 멈춥니다.
6문제 이하이면 해설을 확인하고 10문제를 다시 풀 수 있습니다.
재도전할 때 이전 점수는 남지 않습니다.
시간 제한과 개인정보 수집은 없습니다.

4. 게임 주소 변경
기본 주소는 config.js 안의 gameUrl: '../index.html' 입니다.
퀴즈를 게임과 다른 위치에 게시한다면 gameUrl을 실제 공개된 게임 주소로 바꾸세요.
퀴즈 폴더만 단독으로 옮기면 상위 게임 파일이 없으므로 통과 후 게임이 열리지 않습니다.
index.html, image, audio를 포함하는 기존 게임 폴더와의 상대 위치를 유지하세요.

5. 샘퀴즈 사용
샘퀴즈_입력용_10문항.txt는 HTML과 동일한 문항 데이터에서 생성했습니다.
문항 유형, 보기, 정답, 해설을 샘퀴즈 문항 편집기에 옮겨 적으면 됩니다.
서비스의 자동 업로드 형식 또는 70점 자동 이동 기능을 보장하는 파일은 아닙니다.
샘퀴즈에 실제 등록하거나 공개 링크를 만드는 작업은 포함되지 않았습니다.
학생들이 다른 기기에서 접속할 게임 공개 URL이 있으면 해당 주소를 안내에 넣으세요.
공개 게임: https://kkankong32-alt.github.io/fraction-cafe/
공개 퀴즈: https://kkankong32-alt.github.io/fraction-cafe/quiz/

6. 채점 방식
선택형·OX는 선택한 보기, 순서완성형은 네 카드 전체 순서로 채점합니다.
단답형은 빈칸의 자연수만 입력합니다. 앞뒤 공백과 전각 숫자는 정규화합니다.
초성퀴즈는 완성된 낱말 '분모'를 입력해야 합니다.
자유 서술형 자동 채점의 오류를 피하기 위해 서술형은 포함하지 않았습니다.

7. 유의 사항
이것은 수업용 입장 활동이며 보안·인증 장치가 아닙니다.
원래 게임 주소로 직접 접속하거나 파일을 수정하면 퀴즈를 건너뛸 수 있습니다.
네트워크 서버 없이 동작하는 HTML 특성상 이런 접근까지 차단하지 않습니다.
학교가 요구하는 강제 접근 제한이 필요하면 별도의 서버 인증 방식이 필요합니다.
